the worst case complexity is the maximum time the algorithm takes for the worst case input. 

We are interested in an upper bound 

Linear search

goes through array one at a time and compares against x value

best case complexity is O(1)

worst case time complexity is 
O(n)

we could say the the time complexity is O(n^2) - but this is not the best upper bound ( smallest )

The best upper bound gives the most precise answer 

We cannot search an unsorted array with a better complexity than O(n)

If it is sorted - we can improve this using Binary Search - O(log(n)) complexity
